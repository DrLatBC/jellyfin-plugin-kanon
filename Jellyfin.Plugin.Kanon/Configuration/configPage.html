Badges

Displays a visual tag (e.g. "Canon", "Filler", or "Mixed") on individual episode detail pages to clearly indicate episode classification.
Displays a visual tag (e.g. "Canon", "Filler", or "Mixed") next to each episode in season episode lists for quick identification.
Applies color styling to canon and filler badges (for example, green for Canon and red for Filler) to improve visual recognition. Disabling this option will render all badges in a neutral gray.
File Transformation Plugin Required
Badges require the File Transformation plugin to work. Install it here, then restart Jellyfin. Tagging, filler skipping and playlists work without it.

Defines how the plugin determines which series in your library are considered anime.
Tag name to match when identification mode includes "Tag". Default: Anime

Filler skipping

Each class below can be covered by a media segment spanning the whole episode. Whether that episode is then skipped, offered with a skip button, or played is decided per user under Settings → Playback → Media Segment Actions, using the segment type picked here. After changing these, run the "Update Filler Skip Segments" task.

No-filler playlists

Filler is always left out. Run "Build No-Filler Playlists" again after changing this.
